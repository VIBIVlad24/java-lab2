# Мини-СУБД на Java (Лабораторная работа 2)

## 1. Архитектура системы
Проект разделен на три основных класса:
* Main: Консольный интерфейс. Принимает команды от пользователя и передает их парсеру.
* Parser: Отвечает за разбор SQL-запросов с помощью регулярных выражений и вызывает нужные методы базы данных.
* Database: Управляет таблицами, проверяет уникальность id и сохраняет данные в файл db.dat.
    * Внутренний класс Table: Хранит строки и индексы. Отвечает за пересборку индексов, если данные изменились (после UPDATE или DELETE).

## 2. Инструкция пользователя
1. Скомпилируйте проект: javac src/*.java
2. Запустите программу: java src/Main
3. Вводите запросы в консоль (точку с запятой ; в конце ставить необязательно).
4. Для выхода и сохранения данных введите EXIT. Для просмотра подсказки введите HELP.

Примеры команд:
* INSERT INTO cars VALUES (1, 'Toyota', 25000.0, TRUE, '2023-01-01');
* INSERT INTO cars (id, brand) VALUES (2, 'BMW');
* SELECT * FROM cars WHERE price > 20000;
* CREATE INDEX idx_cars_brand ON cars (brand);
* UPDATE cars SET price = 30000 WHERE id = 2;
* DELETE FROM cars WHERE brand = 'Toyota';

## 3. Результаты тестирования производительности
Для теста было создано 10 000 записей в таблице.
* Без индекса: SELECT по условию WHERE занимает около 150 мс, так как идет полный перебор всех строк (O(N)).
* С индексом: SELECT по индексированному полю занимает около 2 мс, так как используется хеш-таблица (O(1)).
  Вывод: С индексом поиск работает в разы быстрее.
