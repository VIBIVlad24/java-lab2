Мини-СУБД на Java (Лабораторная работа 2)

## 1. *Архитектура системы:*
- **Main**: Консольный интерфейс (точка входа).
- **Database**: Отвечает за хранение таблиц, сериализацию (сохранение/загрузку из `db.dat`). Внутри реализован класс `Table`.
- **Table**: Хранит строки (`List<Map<String, Object>>`) и индексы (`Map`). Реализует логику вставки с проверкой уникальности.
- **Parser**: Принимает на вход строку, использует регулярные выражения (Regex) для разбора SQL-запросов и вызывает соответствующие методы БД.

## 2. *Инструкция пользователя:*
  1. Скомпилируйте проект: `javac *.java`
  2. Запустите программу: `java Main`
  3. Вводите запросы в консоль (оканчивать точку с запятой `;` необязательно). 
  4. Для выхода и сохранения данных введите `EXIT`.
  
## 3. *Результаты тестирования производительности:*
- **Без индекса**: SELECT по условию WHERE занимает ~150 мс (полный перебор O(N)).
- **С индексом**: SELECT по индексированному полю занимает ~2 мс (доступ по хэш-таблице O(1)).
Вывод: Использование индексов кратно ускоряет выполнение поисковых запросов.

## 4. *Выводы:*
В ходе работы была разработана упрощенная СУБД с поддержкой CRUD-операций и базового парсинга SQL.

и алгоритм хеш-индексирования для оптимизации поиска.
